# Wick's Journey

Wick's Journey est un jeu de puzzle-aventure 3D en low-poly, dans lequel le joueur incarne Wick, une petite bougie animée piégée dans une mystérieuse grotte. À travers des boucles temporelles et des énigmes captivantes, Wick doit naviguer dans un univers souterrain riche en dangers et en secrets, tout en cherchant à lever une malédiction ancienne.

## Contexte et Histoire

Dans un monde où les bougies sont les âmes d’anciens aventuriers piégés par la "Pierre du Temps", Wick est condamné à revivre en boucle sa quête. Seul à pouvoir se rappeler des échecs passés, il explore des villages et des zones de la grotte marquées par des épreuves basées sur les sept péchés capitaux. Chaque étape de son périple dévoile davantage sur sa vie antérieure, et il devient essentiel pour lui de comprendre cette malédiction pour briser la boucle.

## Fonctionnalités du Jeu
- Exploration et Aventure : Parcourez un vaste réseau de grottes, des cascades scintillantes aux tunnels de cristaux.

- Énigmes Basées sur la Lumière : Utilisez les capacités de Wick en tant que bougie pour résoudre des puzzles nécessitant des interactions subtiles avec la lumière, la chaleur et l'obscurité.

- Système de Reset : À chaque échec, Wick revient au début, mais avec une meilleure compréhension des dangers et des secrets du monde.

- Gestion des Ressources : Wick doit surveiller l'état de sa flamme, qui s'éteint progressivement, le forçant à chercher de la cire pour survivre.

- Thèmes Profonds : Exploration des sept péchés capitaux à travers des zones de jeu uniques qui dévoilent des fragments de la mémoire de Wick.

## Installation et Démarrage

Prérequis
- Unity (version recommandée : 202X.X.X)
- Git
- Un compte sur GitHub pour accéder au repository privé.

### Installation

1- Clonez le repository GitHub :
```bash
git clone https://github.com/ton_organisation/Wicks-Journey.git
cd Wicks-Journey
```

2- Ouvrez le projet dans Unity.

3- Installez les dépendances nécessaires via le Package Manager d'Unity si elles ne sont pas installées automatiquement.

### Lancement du Jeu
Dans Unity :

1- Ouvrez la scène principale située dans le dossier Assets/Scenes.

2- Appuyez sur le bouton Play pour tester le jeu dans l'éditeur.

## Structure du Projet

- Assets/ : Contient tous les assets du jeu, y compris les modèles 3D, les textures, les scripts, et les scènes.
    - Scenes/ : Fichiers de scènes Unity.
    - Scripts/ : Scripts en C# pour les mécaniques de jeu.
    - Models/ : Modèles 3D pour les personnages, les objets et les environnements.
    - UI/ : Éléments d'interface utilisateur.
- Docs/ : Documentation du projet, y compris les concept arts, les notes de design, et les informations techniques.
